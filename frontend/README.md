# Gigo · Mini App

Telegram Mini App: биржа подработки в Москве. Заказчик публикует заявку, исполнитель находит её в ленте или на карте
и откликается, заказчик принимает отклик, после этого обе стороны видят Telegram-контакт друг друга и оставляют отзывы.
Платежей нет.

React 18 + TypeScript + Vite, без UI-библиотек; цвета берутся из темы Telegram (`--tg-theme-*`), в обычном браузере
работают светлая и тёмная темы.

Контракт API: [`../docs/api.md`](../docs/api.md).

## Бренд и иконки

- **Знак** — булавка карты, в которую вписана «G»; **надпись** «gigo» нарисована линиями (не зависит от шрифтов).
- **Цвет бренда** `#FF6B2C` (оранжевый) — только для акцентов: знак, новые отклики, заголовки разделов формы.
  Для оранжевого текста — `--brand-ink` (`#C2410C` в светлой теме, `#FF9A66` в тёмной), контраст ≥ 4.5.
  Фон, текст и кнопки берутся из темы Telegram (`--tg-theme-*`), поэтому приложение выглядит родным в обеих темах.
- **Тёмная тема** внутри Telegram: `telegram.ts` ставит `<html data-theme>` по `Telegram.WebApp.colorScheme`
  (и по событию `themeChanged`); вне Telegram работает `prefers-color-scheme`.
- **Иконки** — `src/components/Icon.tsx`: один набор inline SVG 24×24, линия 1.9, `currentColor`, без библиотек
  (навигация, действия, факты заявки и 10 категорий: `categoryIcon(id)`). Emoji в интерфейсе не используются.
- Логотип в приложении — `src/components/Logo.tsx` (`<Logo>`, `<LogoMark>`).
- Файлы: `public/logo.svg` (знак + надпись, сам переключает цвет надписи в тёмной теме), `public/favicon.svg` (знак),
  `../docs/brand/` — исходники и PNG для BotFather: `bot-avatar-512.png` (аватар бота, переживает обрезку в круг)
  и `miniapp-640x360.png` (обложка Mini App). PNG перерисовываются из `avatar.html` / `cover.html` скриншотом Chromium.

## Экраны

- **Что вы ищете?** — логотип, «как это работает» в три шага, выбор роли с подсказкой, что будет дальше.
- **Исполнитель:** Лента (закреплённые фильтры: категории, рядом, сегодня, метро, оплата; «Уведомлять о таких»;
  скелетоны, «потяните, чтобы обновить» и кнопка обновления), Карта, Отклики (сначала «Вас выбрали»), Профиль.
- **Заказчик:** Мои заявки (заявки с новыми откликами сверху и подсвечены), Создать (разделы, проверка полей на лету,
  запоминает категорию, метро, единицу оплаты и «когда платите»; предпросмотр карточки), Профиль.
- **Заявка:** факты с иконками, карточка заказчика, совет по безопасности, «Поделиться», «Пожаловаться» (причина + текст);
  «Откликнуться» — Telegram MainButton или закреплённая кнопка внизу; автору — управление набором и отклики.
- **Профиль:** аватар, рейтинг, роль, «О себе», подписки, справка «Как это работает / Безопасность / Как пожаловаться».
- **Блокировка:** `403` «Аккаунт заблокирован…» на любом запросе показывает экран «Доступ ограничен»; `429` — текст сервера.

## Команды

Нужен Node.js 20+.

```bash
cd frontend
npm install

npm run dev          # http://localhost:5173, /api проксируется на http://localhost:8000
npm run dev:mock     # без бэкенда: данные и логика в src/mock (состояние в памяти до перезагрузки)
npm run build        # tsc --noEmit + сборка в dist/
npm run build:mock   # сборка с тестовыми данными (для демо)
npm run preview      # раздать dist/ на http://localhost:4173 (с тем же прокси /api)
npm run typecheck
```

### Разработка без Telegram

Запустите бэкенд с `DEV_AUTH=1`: заголовок `Authorization: tma <initData>` отправляется только внутри Telegram,
без него сервер считает вас пользователем 1. Чтобы войти другим пользователем (например, заказчик в одной вкладке,
исполнитель в другой), откройте `http://localhost:5173/?devUser=2` — dev-сборка пошлёт `X-Dev-User: 2`.
Можно и `localStorage.gigoDevUser = '2'`, но параметр в адресе важнее и не общий для вкладок. В продакшен-сборке заголовка нет.

### Режим mock

Пользователь мока — «Алексей» без роли, поэтому сначала показывается выбор роли. У него уже есть отклики (принятый,
ожидающий, отклонённый) и две свои заявки с откликами. Для живости: свой отклик через 6 секунд «принимается»,
на новую заявку через 4 и 9 секунд приходят отклики. Текст с «предоплатой за обучение» и т.п. вернёт 422.
Жалоба отвечает 204 (11-я за сессию — 429). `?mockBlocked=1` показывает экран блокировки.

## Переменные окружения

Кладите в `frontend/.env.local` (не коммитится), образец в `.env.example`.

| Переменная | Зачем |
|---|---|
| `VITE_YANDEX_MAPS_KEY` | ключ JavaScript API Яндекс Карт 2.1. Без него вкладка «Карта» показывает заглушку |
| `VITE_BOT_USERNAME` | имя бота без @ для ссылки «Поделиться» (можно в корневом `.env`) |
| `VITE_MINIAPP_NAME` | короткое имя Mini App из BotFather, если ссылка вида `t.me/<бот>/<имя>` |
| `VITE_MOCK` | `1` — работать на тестовых данных без бэкенда (то же делает `--mode mock`, см. `.env.mock`) |

## Как устроено

- `src/api.ts` — типизированный клиент всех ручек из `docs/api.md`, типы в `src/types.ts`.
- `src/App.tsx` — `/api/me` и `/api/meta`, вкладки по роли, стек экранов поверх вкладок (заявка, профиль, подписки)
  с записями в `history`, чтобы работали «назад» браузера и Telegram BackButton.
- `src/telegram.ts` — `Telegram.WebApp`: `ready()`, `expand()`, BackButton, MainButton (`src/mainButton.ts`), ссылки, deep link.
- `src/screens/` — Onboarding, Feed, MapView, MyResponses, MyJobs, CreateJob, JobDetail, Profile, UserProfile, Subscriptions.
- `src/components/` — карточка заявки, фильтры, выбор метро, шторка, отзыв, общие мелочи (`ui.tsx`: статус, аватар, звёзды).
- `src/filters.ts` — фильтры ленты (запоминаются в `localStorage`), запрос к API, имя подписки.
- `src/mock/` — фикстура и имитация API для `VITE_MOCK=1`.

Ссылки: `?job=42` (заявка), `?tab=responses`, `?tab=my`, `?tab=create`, `?tab=profile`; в Telegram то же через
`startapp=job_42`, `startapp=tab_create` и т.д.

«Поделиться» в заявке даёт ссылку `t.me/<VITE_BOT_USERNAME>[/<VITE_MINIAPP_NAME>]?startapp=job_42` через окно выбора
чата Telegram; без имени бота копирует текст заявки.
