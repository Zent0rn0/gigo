# API Gigo

Базовый путь `/api`. Ответы в JSON. Даты в ISO 8601 с часовым поясом.
Ошибки: `{"detail": "текст для человека"}` с кодом 400/401/403/404/409/422.

## Вход

Каждый запрос из Mini App несёт заголовок

    Authorization: tma <Telegram.WebApp.initData>

Сервер проверяет подпись initData токеном бота. Без заголовка или с плохой подписью: `401`.
Первый запрос создаёт пользователя без роли (`role: null`): Mini App показывает выбор роли.

При `DEV_AUTH=1` на сервере заголовок необязателен: пользователь id 1. Заголовок `X-Dev-User: 2`
входит другим пользователем (удобно проверять заказчика и исполнителя в двух вкладках браузера).

## Роли

- `employer`, заказчик: создаёт заявки, смотрит отклики, принимает или отклоняет.
- `worker`, исполнитель: смотрит ленту и карту, откликается, подписывается на новые заявки.

Роль выбирается при первом входе и меняется в профиле. Действие не своей роли: `403`.

## GET /api/me

```json
{
  "id": 777, "username": "ivan", "first_name": "Иван",
  "role": "worker",
  "about": "Опыт на складе 2 года",
  "rating": 4.7, "reviews_count": 3
}
```

`rating` равен `null`, пока нет отзывов.

## PATCH /api/me

Тело (любое из полей): `{"role": "employer", "about": "..."}`. Ответ: как `GET /api/me`.

## GET /api/meta

```json
{
  "categories": [{"id": "loader", "label": "Грузчики", "emoji": "📦"}, ...],
  "pay_units": [{"id": "hour", "label": "за час"}, {"id": "shift", "label": "за смену"},
                {"id": "day", "label": "за день"}, {"id": "task", "label": "за работу"}],
  "metro": [{"id": "7.1", "name": "Таганская", "line": "Таганско-Краснопресненская", "color": "#943E90", "lat": 55.73, "lng": 37.65}, ...],
  "city": {"id": "moscow", "name": "Москва", "lat": 55.7558, "lng": 37.6176}
}
```

## GET /api/jobs

Лента: открытые и не просроченные заявки всех заказчиков.

| Параметр | Пример | Смысл |
|---|---|---|
| `category` | `category=loader&category=courier` | одна или несколько категорий |
| `pay_min` | `400` | ₽/час от |
| `metro` | `metro=7.1&metro=1.5` | станции метро |
| `today` | `true` | только на сегодня |
| `lat`, `lng` | `55.73`, `37.65` | где пользователь: включает `distance_km` |
| `radius_km` | `5` | только в радиусе (нужны `lat`, `lng`) |
| `sort` | `fresh` \| `distance` \| `pay` | по умолчанию `fresh` |
| `with_location` | `true` | только с точкой на карте |
| `limit`, `offset` | `30`, `0` | страница; `limit` до 500 |

Ответ: `{"total": 124, "items": [Job, ...]}`.

### Job

```json
{
  "id": 42,
  "status": "open",
  "category": "loader",
  "title": "Грузчики на переезд офиса",
  "description": "Мебель и коробки, лифт есть.",
  "workers_needed": 2,
  "pay_amount": 500, "pay_unit": "hour",
  "pay_per_hour": 500, "pay_estimated": false,
  "pay_total": 2000,
  "pay_timing": "сразу",
  "starts_on": "2026-10-11",
  "starts_at": "2026-10-11T14:00:00+03:00",
  "duration_hours": 4,
  "metro": {"id": "7.1", "name": "Таганская", "line": "Таганско-Краснопресненская", "color": "#943E90"},
  "address": "ул. Марксистская, 3",
  "lat": 55.7393, "lng": 37.6533,
  "distance_km": 1.8,
  "employer": {"id": 900000001, "first_name": "Ольга", "rating": 4.8, "reviews_count": 12},
  "responses_count": 3,
  "accepted_count": 1,
  "is_mine": false,
  "my_response": null,
  "created_at": "2026-10-11T13:02:00+03:00",
  "expires_at": "2026-10-11T15:00:00+03:00"
}
```

- `pay_per_hour` пересчитан в ₽/час; `pay_estimated: true`, если считали смену за 8 часов.
- `is_mine`: заявку создал текущий пользователь.
- `my_response`: отклик текущего пользователя на эту заявку, объект `Response` (см. ниже) или `null`.

## GET /api/jobs/{id}

Одна заявка в виде `Job`. Закрытую заявку видят только её автор и те, кто откликался; остальным `404`.

Автору заявки дополнительно приходит `"responses": [Response, ...]` (все отклики, новые сверху).

## POST /api/jobs (заказчик)

```json
{
  "category": "loader",
  "title": "Грузчики на переезд офиса",
  "description": "Мебель и коробки, лифт есть.",
  "workers_needed": 2,
  "pay_amount": 500, "pay_unit": "hour",
  "pay_timing": "сразу",
  "starts_on": "2026-10-11",
  "start_time": "14:00",
  "duration_hours": 4,
  "metro_id": "7.1",
  "address": "ул. Марксистская, 3",
  "lat": null, "lng": null
}
```

Обязательны `category`, `title`, `pay_amount`, `pay_unit`, и хотя бы одно из `metro_id`, `address`, (`lat`,`lng`).
Точка на карте: `lat`/`lng`, если переданы; иначе адрес через геокодер; иначе координаты станции метро.
Заявка живёт до часа после начала, до конца дня `starts_on` или 3 дня, если дата не указана.
Тексты с признаками мошенничества (закладки, оформление карт, предоплата за обучение и т.п.) не принимаются: `422`.
Не больше 20 открытых заявок у одного заказчика: `409`.
Ответ `201` с `Job`.

## PATCH /api/jobs/{id} (автор заявки)

`{"status": "closed"}` (набрали людей или работа сделана), `"cancelled"` (отменена) или `"open"` (открыть снова,
если не просрочена). Ответ: `Job`.

## GET /api/my/jobs (заказчик)

Заявки текущего пользователя, все статусы, новые сверху: `{"items": [Job, ...]}`.
Поле `pending_count` в каждой: сколько откликов ждут решения.

## POST /api/jobs/{id}/responses (исполнитель)

`{"message": "Могу к 14:00, есть опыт"}` (необязательно, до 500 знаков). Ответ `201` с `Response`.
Повторный отклик после отзыва (`withdrawn`) возвращает его в `pending`. На свою или закрытую заявку: `409`.
Заказчик получает сообщение от бота.

### Response

```json
{
  "id": 7,
  "job_id": 42,
  "status": "pending",
  "message": "Могу к 14:00, есть опыт",
  "created_at": "2026-10-11T13:10:00+03:00",
  "worker": {"id": 777, "first_name": "Иван", "about": "...", "rating": 4.7, "reviews_count": 3},
  "contact": null,
  "my_review": null
}
```

- `status`: `pending` ждёт решения, `accepted` принят, `rejected` отклонён, `withdrawn` исполнитель отозвал.
- `contact` заполнен только у принятого отклика, и показывает ту сторону, которой нет у смотрящего:
  заказчику контакт исполнителя, исполнителю контакт заказчика.
  `{"first_name": "Ольга", "username": "olga", "url": "https://t.me/olga"}`; без username: `"url": "tg://user?id=900000001"`.
- `my_review`: отзыв, который смотрящий уже оставил второй стороне по этой заявке: `{"rating": 5, "text": "..."}` или `null`.

## PATCH /api/responses/{id}

- Автор заявки: `{"status": "accepted"}` или `{"status": "rejected"}`.
- Исполнитель: `{"status": "withdrawn"}` (только из `pending` или `accepted`).

Ответ: `Response`. Вторая сторона получает сообщение от бота; при принятии обоим приходят контакты.

## GET /api/my/responses (исполнитель)

Отклики текущего пользователя, новые сверху: `{"items": [{...Response, "job": Job}, ...]}`.

## POST /api/reviews

`{"response_id": 7, "rating": 5, "text": "Всё чётко"}`. Оставить отзыв может любая сторона принятого отклика
о второй стороне. Повторный вызов заменяет отзыв. Ответ `201`: `{"rating": 5, "text": "Всё чётко"}`.

## GET /api/users/{id}

Публичный профиль:

```json
{
  "id": 900000001, "first_name": "Ольга", "role": "employer", "about": "...",
  "rating": 4.8, "reviews_count": 12,
  "jobs_count": 30,
  "reviews": [{"rating": 5, "text": "...", "author": {"id": 777, "first_name": "Иван"},
               "job_title": "Грузчики на переезд", "created_at": "..."}]
}
```

`jobs_count`: у заказчика созданные заявки, у исполнителя принятые отклики.

## Подписки (исполнитель)

`GET /api/subscriptions`, `POST /api/subscriptions`, `DELETE /api/subscriptions/{id}`.

```json
{"id": 1, "name": "Грузчики от 400", "categories": ["loader"], "pay_min": 400, "metro_ids": [],
 "lat": null, "lng": null, "radius_km": null, "today_only": false, "enabled": true}
```

Бот присылает новые заявки, подходящие под подписку. Не больше 10 подписок.

## POST /api/jobs/{id}/report

Пожаловаться на чужую заявку: `{"reason": "scam" | "spam" | "rude" | "other", "text": "..."}` (`text` до 500 знаков,
необязателен). Ответ `204`. Повторная жалоба того же человека на ту же заявку заменяет прежнюю.
Модераторы получают её в бота. Заявка с 3 жалобами от разных людей скрывается из ленты до решения модератора.

## Ограничения и блокировки

- Слишком частые действия: `429` с `detail` для человека («Слишком много откликов за час, попробуйте позже»).
  Лимиты: 5 заявок в час, 30 откликов в час, 10 жалоб в сутки, 60 запросов в минуту на изменения.
- Заблокированный модератором пользователь получает `403` с `detail` «Аккаунт заблокирован…» на любой запрос.

## Ссылки из бота

Кнопки бота открывают Mini App с параметром: `?job=42` (заявка), `?tab=responses` (мои отклики),
`?tab=my` (мои заявки), `?tab=create` (новая заявка), `?tab=profile`. Внутри Telegram тот же параметр приходит как `start_param` вида `job_42`, `tab_create`.
